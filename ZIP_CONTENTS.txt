Acoustic Topo-Lock project archive

Includes the application, both source packages, tests, notebooks, configuration, documentation, research directory structure and UI screenshots.
The references directory contains the supplied notebook and research blueprint.
Virtual environments, Git internals, caches, logs, secrets, temporary work and unrelated document/video exports are excluded. The training folder is included directly.
The full-run metrics.json and diagnostic PNGs were not present in the accessible source files.

After extraction, open PowerShell inside Acoustic-Topo-Lock and run:
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
