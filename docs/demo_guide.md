# Demo guide

1. Launch Streamlit from the checkout.
2. Open **Audio Analysis** to inspect the waveform, spectrogram, and DSP features of a generated recording.
3. Open **Authentication**, select **Demo**, and run **Room matches, replay detected**. The rejection comes from the illustrative replay status while the room status passes.
4. Run the scenario with room and replay evidence unavailable to see partial verification.
5. Switch to **Real** and upload a suitable WAV or FLAC. An empty install explains which models are unavailable.

All illustrative decisions carry **DEMO DATA — NOT A REAL MODEL PREDICTION**. The CLI supports the same scenarios through `python -m scripts.run_demo --help`.
